# Security policy

## Supported versions

This project has not declared a generally available production release. Security fixes are applied
to the current `main` branch; do not infer production support from an image, tag, or repository
artifact unless a release receipt and support agreement explicitly say so.

## Report a vulnerability

Use GitHub's private vulnerability reporting for this repository. Do not open a public issue for a
suspected vulnerability and do not include customer data, credentials, tokens, private keys, or
live exploit details in a report.

Include the affected commit, tag, image digest, component, deployment shape, reproduction steps,
impact, and any suggested containment. The project does not currently claim a staffed 24x7
response SLA; enterprise response staffing and notification procedures are tracked as an open
deployment gate in [`docs/enterprise-readiness.json`](docs/enterprise-readiness.json).

Release and admission requirements are defined in
[`docs/RELEASE-ASSURANCE.md`](docs/RELEASE-ASSURANCE.md). Operational response steps are in
[`docs/incident-response.md`](docs/incident-response.md).
